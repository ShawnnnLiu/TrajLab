# Weekly meeting briefs

One file per team meeting, named by the meeting date: `YYYY-MM-DD.html` (or `.md` when a rendered page is not needed).
Each brief is the material presented at that meeting and is frozen once the meeting has happened.
Follow-ups and decisions go into the next brief, or into an ADR under `docs/decisions/` when they change what a trial records.
